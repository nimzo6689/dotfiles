## 🏛️ Architecture Decision Records (ADR)

このリポジトリにおける主要なツールの選定理由や、設計方針の決定履歴を記録しています。  
詳細な記述は各リンク先のファイルを参照してください。

### ステータス凡例
* 🟢 **Accepted**: 現在採用中の決定
* 🟡 **Proposed**: 検討中・提案中の決定
* 🔴 **Superseded**: 過去の決定（別の決定に置き換え済み）
* ⚪ **Deprecated**: 廃止・撤回された決定
